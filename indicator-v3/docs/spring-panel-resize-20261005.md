# Movable and resizable filming panels

SpringPanelResize is an unsealed presentation module. Both the telemetry panel and trading chart have a move bar above their body, a right-edge width handle, a bottom-edge height handle, and a bottom-right corner for both dimensions. They move and resize independently and may overlap. Clicking or dragging a panel brings its ScreenGui forward. Reset layout on either panel restores both default positions and sizes. Global mouse/touch drag handling continues outside the handle until release.

The telemetry ScrollingFrame has a UIScale with fixed 440 logical width and inverse logical height. Its scrollbar is on the left so the right resize handle does not intercept scrollbar dragging. The chart plot uses its existing relative layout, and its header readout avoids the title at narrow widths. Each panel is bounded independently by the viewport, including its 24-pixel move bar; the chart no longer reserves space for the telemetry panel. Preferences live in the owned SpringPanelSizePreferences folder and survive showcase reopening. Both GUIs, DisplayOrder values, scrollbar position, and all created callbacks restore on controller lifecycle cleanup. No camera or data changes.

CoreGui.RoAlgoSpringLayoutControl supports status, set({panelWidth,panelHeight,panelX,panelY,chartWidth,chartHeight,chartX,chartY}), and reset. Coordinates refer to the top-left of each body. Future SpringArrayReplay mounts/owns the resizer; the current session received it in place without a data reload. Source compilation passed. In actual Edit-mode CoreGui, acceptance verified a 320×420 panel at (40,80), a 700×260 chart at (120,180), intentional overlap, independent resizing, extreme viewport clamps, all eight active move/resize handles, exact preference restoration, and zero UI errors. Playback remained paused at the same row/layer, at fixed 6 ticks per second; camera CFrame was unchanged. Native mouse automation is Client-only, so automated Edit-mode dragging was not performed; input handlers were reviewed. Evidence: evidence/spring-panel-movement-20261005.json.
