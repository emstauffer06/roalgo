# RoAlgo learned mechanical decision system

Approved in conversation on October 5, 2026: expand the existing showcase into learned BUY (long), SELL (short), HOLD and CLOSE decisions, multiple market timescales, explicit regime context, and controlled native-physics comparisons. Use Roblox MCP only for Studio interaction. Do not request the same approval again.

Build separately in `indicator-v2/`, preserving the existing indicator and the earlier eight-hour experiment. This is a local research instrument, with no orders, credentials, cloud publishing or claimed novel financial edge. The older 24-node experiment already failed to demonstrate incremental eight-hour forecasting value. Its 2025–2026 results have been inspected; no date range in the existing research cache will be called an untouched project-level holdout.

The new distinction is a learned position decision objective, causal integration of five-minute/hourly/daily inputs, a fitted regime filter, matched ablations, and an inspectable physical state. Use a 24-body three-bank network with both coupled and disconnected native variants stepped together. A mathematical counterpart implements the same modeled mechanics; solver differences are measured rather than claimed to be new information. Physical parameters stay fixed for this first experiment.

Learn regularized readouts for forward returns and adverse/favorable excursions from historical inputs, with every label completed before its fitting cutoff. Use chronological train/validation/evaluation sessions. Fit scalers on training only, select regularization on validation only, freeze before evaluation. The first Studio experiment uses 20 training, 5 validation and 5 evaluation sessions ending December 31, 2024; the loader supports larger research windows. This first run is an integration/research demonstration, not statistical proof.

Use only completed observations. Daily context is previous-session data, hourly context has completed before the five-minute decision close, and model parameters never use later test data. A three-state Gaussian hidden Markov model is fitted on daily history available before the first decision bar; forward filtering provides current probabilities. State names describe fitted volatility levels and do not assert economic causation.

Signals act on the next observed open. One long or short position maximum, no pyramiding or direct same-bar reversal. Costs apply on each side, short borrow accrues over elapsed time, gaps execute at observed prices, ambiguous stop/target bars use stop-first, and final open exposure is marked rather than inventing an execution. Safety stops and a maximum holding period remain explicit rules.

The UI must show data coverage/splits, train/validation/evaluation status, BUY/SELL/CLOSE/HOLD, position, costs and metrics, trained model status, action-score contributions, network energy, inspectable input forces, a bank/link ablation selector, and recorded replay. Comparisons and visual explanations are measured diagnostics, not proof of causality. New package and launcher coexist with v1; stop/hide v1 only in the selected RoAlgo instance when opening v2.
